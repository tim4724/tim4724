Android engineer in Fürth, Germany. I work on system apps in Android Automotive OS. Before that I worked on the Kinegram Mobile Chip SDK, Android and iOS libraries that verify electronic passports over NFC.

In my own time I build party games where phones are the controllers and a shared screen is the display:

- [Paper Balloon Controller](https://github.com/tim4724/PaperBalloon-Controller): the controller app, Jetpack Compose on Android and SwiftUI on iOS. [App Store](https://apps.apple.com/us/app/paper-balloon-controller/id6825072879)
- [Tiny Track Party](https://github.com/tim4724/Tiny-Track-Party): kart racer with one C++ engine for the browser, Android TV and Apple TV. [tinytrack.paperballoon.games](https://tinytrack.paperballoon.games)
- [HexStacker Party](https://github.com/tim4724/HexStacker-Party): party game for one to eight players in the browser, also on Apple TV. [hexstacker.com](https://hexstacker.com)
- [Party-Sockets](https://github.com/tim4724/Party-Sockets): the WebSocket relay server behind them.
